# CardStack Web

Next.js (App Router) web client for CardStack.

See the [root README](../../README.md) for monorepo setup. Common commands live in the root `Makefile`:

```sh
make web-install   # bun install
make web-dev       # next dev (via Doppler)
make web-build     # next build (via Doppler)
make web-start     # next start (via Doppler)
make web-lint      # eslint
```

App-specific conventions: [AGENTS.md](./AGENTS.md).
